## 💎 Hollywood AAA Features & Architecture

### 🏙️ Real-Time 3D WebGL Cyber Megacity
- Built with `@react-three/fiber` & `Three.js` running persistently at 60–120 FPS.
- **95+ Glowing Neon Skyscrapers** with procedural rooftop laser beacons.
- **2,500 Starfield Cyber Nebula** with celestial particles and fluid Aurora wave clouds.
- **4-Ring Dyson Gyroscope Quantum Core** with 450 orbiting plasma particles.
- **28 High-Speed Photon Vehicles** streaming across multi-tier atmospheric skyways.
- **3D Cursor Light Probe** tracking mouse and gyroscope coordinates in physical 3D space.

### 🃏 Mathematical 3D Holographic Foil Cards (`HoloCard`)
- Interactive mathematical 3D perspective tilt calculated on `perspective(1000px)`.
- Dynamic radial prismatic foil rainbow glare sheen and diagonal scanline specular streaks.
- Dual input driver: desktop mouse coordinate tracking + mobile touchscreen gyroscope drag parallax.

### 🔊 Zero-Latency Web Audio API Synthesizer Engine
- Generates 100% synthesized soundscapes in real-time without external audio files.
- Real-time oscillator waveforms for tactile clicks, frequency chirps, hyper-warp chords, and access chimes.
- Interactive **`[ 🔊 AUDIO: ON / 🔇 MUTED ]`** HUD switch with mobile hardware haptic feedback (`navigator.vibrate`).

### 📟 Cybernetic Command Terminal (`CLI`)
- Fullscreen interactive command-line interface accessible via the **`[ 📟 TERMINAL ]`** launcher.
- Direct executable commands: `tracks`, `prizes`, `timeline`, `rules`, `register`, `status`, `clear`, `help`.
- Teleports the user directly to any section of the website.

### 📱 Ergonomic 5-Key Mobile Cyber Dock
- Designed specifically for smartphone ergonomics without horizontal scrolling clutter:
  - **`[ ⚡ GENESIS ]`**: Instant return to summit.
  - **`[ 🌐 TRACKS ]`**: 03 Official Competition Tracks.
  - **`[ 🏆 PRIZES ]`**: ₹1,50,000+ Prize Vault.
  - **`[ 📅 ROADMAP ]`**: Event Timeline & Stage Dossiers.
  - **`[ 🚀 UNSTOP ]`**: Direct Registration Gateway.
- Native safe-area insets (`env(safe-area-inset-bottom)`) for iPhone home bars and Android navigation pills.
- Standalone **PWA Web App Manifest** (`manifest.json`) for fullscreen home screen installation.

## 🚀 Getting Started (Local Development)

### 1. Clone the Repository
```bash
git clone https://github.com/HarshDev-byte/Enigma-5.0.git
cd "Enigma 5.0"
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### 4. Build Production Bundle
```bash
npm run build
npm run start
```
